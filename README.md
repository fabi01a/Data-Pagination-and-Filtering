# Data Pagination and Filtering

## Project Overview

This project is an interactive student directory built with vanilla JavaScript to practice data pagination, DOM manipulation, and event handling.

The application dynamically displays a maximum of nine student profiles per page, with interactive pagination buttons that allow users to navigate through the directory.

The pagination logic is designed to accommodate datasets of any size, automatically calculating the number of pages required and generating the appropriate navigation buttons based on the number of student records.

## Technologies Used

- **HTML5** – Page structure and content
- **CSS3** – Styling and layout
- **JavaScript (ES6+)** – DOM manipulation, event handling, and dynamic content generation

## What I Learned

This project strengthened my understanding of working with JavaScript arrays, manipulating the DOM, and creating reusable functions to manage dynamic content.

I gained hands-on experience with:

- Using array indexes and calculations to determine which student profiles appear on each page
- Dynamically generating HTML elements using JavaScript
- Creating pagination buttons based on dataset size
- Implementing event listeners to handle page navigation
- Updating the DOM without reloading the page
- Managing active pagination states to provide visual feedback
- Writing reusable functions that accommodate datasets of varying sizes
